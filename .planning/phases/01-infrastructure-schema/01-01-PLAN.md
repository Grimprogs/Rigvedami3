# Plan 01-01: Supabase Infrastructure & Schema
wave: 1

## Goal
Install Supabase client, create environment config, write SQL schema with no foreign keys.

## Tasks

### 1. Install dependency
```
npm install @supabase/supabase-js
```

### 2. Create .env.example
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 3. Create src/integrations/supabase/client.ts
Initialize typed Supabase client with Database generic.

### 4. Create src/integrations/supabase/types.ts
Export all table row types derived from the SQL schema.

### 5. Apply SQL migration
Run supabase/migrations/20260429000000_initial_schema.sql in Supabase dashboard SQL editor.
