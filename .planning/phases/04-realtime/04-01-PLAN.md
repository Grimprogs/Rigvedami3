## Notification Events Architecture
| User Action | DB Trigger | Notification Row |
|---|---|---|
| Employee startTask | tasks.status → in_progress | INSERT notifications (user_id=admin_id, type='task_started') |
| Employee stopTask | tasks.status → pending | INSERT notifications (user_id=admin_id, type='task_stopped') |
| Employee requestCompletion | tasks.status → completion_requested | INSERT notifications (user_id=admin_id, type='completion_requested') |
| Admin approveCompletion | tasks.status → completed | INSERT notifications (user_id=assignee_id, type='completion_approved') |
| Admin rejectCompletion | tasks.status → in_progress | INSERT notifications (user_id=assignee_id, type='completion_rejected') |

Notifications are inserted by a Postgres trigger on tasks table status changes.

### 9. Create SQL notification trigger
```sql
CREATE OR REPLACE FUNCTION public.handle_task_status_change()
RETURNS TRIGGER AS $$
DECLARE admin_id UUID;
BEGIN
  -- Find admin profile id (first admin in system)
  SELECT id INTO admin_id FROM public.profiles WHERE role = 'admin' LIMIT 1;

  IF NEW.status = 'in_progress' AND OLD.status != 'in_progress' THEN
    INSERT INTO public.notifications (user_id, task_id, type)
    VALUES (admin_id, NEW.id, 'task_started');
  ELSIF NEW.status = 'pending' AND OLD.status = 'in_progress' THEN
    INSERT INTO public.notifications (user_id, task_id, type)
    VALUES (admin_id, NEW.id, 'task_stopped');
  ELSIF NEW.status = 'completion_requested' THEN
    INSERT INTO public.notifications (user_id, task_id, type)
    VALUES (admin_id, NEW.id, 'completion_requested');
  ELSIF NEW.status = 'completed' AND OLD.status = 'completion_requested' THEN
    INSERT INTO public.notifications (user_id, task_id, type)
    VALUES (NEW.assignee_id, NEW.id, 'completion_approved');
  ELSIF NEW.status = 'in_progress' AND OLD.status = 'completion_requested' THEN
    INSERT INTO public.notifications (user_id, task_id, type)
    VALUES (NEW.assignee_id, NEW.id, 'completion_rejected');
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_task_status_change
  AFTER UPDATE OF status ON public.tasks
  FOR EACH ROW EXECUTE FUNCTION public.handle_task_status_change();
```
