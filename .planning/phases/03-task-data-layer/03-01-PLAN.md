## Tasks

### 1. Create src/hooks/useProfiles.ts
```ts
// useProfiles(): returns all employee profiles
// useProfile(id): returns single profile
// useCreateProfile(): mutation to create profile (admin creates employee in Supabase Auth + profile)
// useUpdateProfile(): mutation
// useDeleteProfile(): mutation
```
Uses React Query with supabase.from('profiles').select()

### 2. Create src/hooks/useTasks.ts
```ts
// useTasks(): admin gets all tasks; employee gets their assignee_id = user.id
// useCreateTask(): admin mutation
// useUpdateTaskStatus(id, status): employee/admin mutation
// useDeleteTask(): admin mutation
// Workflow helpers:
//   startTask(id) → UPDATE status='in_progress', started_at=NOW()
//   stopTask(id) → UPDATE status='pending'
//   requestCompletion(id) → UPDATE status='completion_requested', completion_requested_at=NOW()
//   approveCompletion(id) → UPDATE status='completed', approved_at=NOW()
//   rejectCompletion(id) → UPDATE status='in_progress'
```

### 3. Update AppContext.tsx
- Remove: `employees`, `tasks` state and all their mutations
- Keep: `notifications` (migrated in Phase 5)
- Keep: `theme`
- Export new hooks from context or directly from hook files
- Update `visibleNotifications` computation (temp: keep local until Phase 5)

### 4. Update page components to use new hooks
Each page swaps `useApp()` reads to equivalent hook:
- `AdminDashboard`: `useTasks()`, `useProfiles()`
- `AdminEmployees`: `useProfiles()`, `useTasks()`, mutations from `useProfiles`
- `AdminCreateTask`: `useProfiles()`, `useCreateTask()`
- `AdminApprovals`: `useTasks()`
- `AdminTasks`: `useTasks()`, `useDeleteTask()`
- `EmployeeDashboard`: `useTasks()`, `useProfile(user.id)`
- `EmployeeTasks`: `useTasks()`
- `EmployeeProfile`: `useProfile(user.id)`, `useTasks()`
- `TaskCard`: workflow mutations from `useTasks`

### 5. Overdue detection
Create a Supabase SQL view or use React Query select transform:
```ts
// In useTasks, transform result:
tasks.map(t => {
  if (t.status === 'completed' || t.status === 'completion_requested') return t;
  const due = new Date(`${t.due_date}T${t.due_time}`);
  if (due < new Date()) return { ...t, status: 'overdue' };
  return t;
})
```
Also add SQL: scheduled Supabase Edge Function or pg_cron for server-side overdue marking.
